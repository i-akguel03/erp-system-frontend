ERP-System Dashboard

Ein modernes Fullstack-ERP-System für Vertrieb, Kunden- und Produktmanagement

Über das Projekt

Unser ERP-System ermöglicht effiziente Verwaltung von Produkten, Kunden und Lagerbeständen. Die moderne Architektur kombiniert ein robustes Backend mit einer dynamischen Angular-Oberfläche.

Backend

Spring Boot, Spring Security & JWT, MSSQL/PostgreSQL

Frontend

Angular, Bootstrap, Responsive Design & interaktive Tabellen

Deployment & CI/CD

Docker, GitHub Actions, Render Cloud oder lokale Server

Starte die Anwendung und verwalte Kunden, Produkte und Bestände effizient!
